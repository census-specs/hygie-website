hygie R package

Hygie — Traitement Interactif des Données sous R

Un outil de préparation et de nettoyage de données inspiré de PowerQuery pour R, avec interface graphique interactive.

Voir sur GitHub

Installation Rapide

Installez la version de développement directement depuis GitHub via le paquet remotes :

R Script 
if (!requireNamespace("remotes", quietly = TRUE)) { install.packages("remotes") }
remotes::install_github("census-specs/hygie")

Fonctionnalités Clés

Sans Code

Importez, filtrez, nettoyez et combinez vos données via des fenêtres de dialogue interactives.

Reproductible

Génère automatiquement le code R équivalent respectant les standards de l'écosystème tidyverse.

Multi-formats

Supporte CSV, Excel (.xlsx, .xls), SPSS (.sav), SAS, Stata, JSON et fichiers natifs RDS.

Historique Dynamique

Visualisez, annulez ou réordonnez chaque étape de transformation pas à pas.

Mode d'emploi

Étape 1 : Lancement de l'application dans R

Après installation, chargez le paquet et lancez l'interface avec la fonction unique :

R Console 
library(hygie)
run_hygie()

Étape 2 : Lancement personnalisé (Optionnel)

Pour lancer l'application sur un port précis sans ouvrir le navigateur externe :

R Console 
run_hygie(port = 3838, launch.browser = rstudioapi::viewer)

Étape 3 : Flux de travail dans l'interface

  1. Importation : Choisissez votre fichier depuis le menu dédié.
  2. Nettoyage & Transformation : Appliquez vos filtres, recodages ou jointures.
  3. Code R & Export : Consultez l'onglet code généré et exportez le résultat final sous le format désiré.

Import & Nettoyage

Apprenez à supprimer les doublons, traiter les valeurs manquantes (NA) et harmoniser la casse des variables textuelles. Suivez pas à pas la sélection des colonnes et la validation instantanée des transformations.

# Code R équivalent généré :
library(dplyr)
library(stringr)

donnees_sante_propre <- donnees_sante %>%
  distinct() %>%
  filter(!is.na(id_patient)) %>%
  mutate(across(where(is.character), ~ str_squish(str_to_title(.x))))
