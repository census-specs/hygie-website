Que peut faire Hygie ? What can Hygie do?

L'idée est simple : vous partez d'un fichier de données parfois désordonné, et Hygie vous aide à le transformer progressivement en un fichier propre et prêt à être utilisé. The idea is simple: start with a dataset that may be messy, and Hygie helps you progressively turn it into clean, analysis-ready data.

Transformation des variables Variable transformation

Nettoyer ses données Clean your data

Supprimez les doublons, repérez les valeurs manquantes, corrigez certaines informations et préparez votre fichier avant l'analyse. Remove duplicates, identify missing values, correct information and prepare your dataset before analysis.

Transformer les données Transform your data

Modifiez les variables, recodez des catégories, créez de nouvelles informations ou filtrez les lignes qui vous intéressent. Modify variables, recode categories, create new information or filter the rows you need.

Travailler avec plusieurs fichiers Work with multiple files

Combinez plusieurs sources de données et réalisez des jointures sans avoir à mémoriser les différentes commandes R nécessaires. Combine multiple data sources and perform joins without having to memorize the different R commands required.

Garder une trace de son travail Keep track of your work

Chaque transformation peut être suivie dans l'historique afin de comprendre comment vos données ont évolué. Every transformation can be followed through the history so you can understand how your data changed.

Générer du code R Generate R code

Vous pouvez retrouver le code R correspondant aux opérations effectuées dans l'interface et le réutiliser dans vos propres scripts. You can retrieve the R code corresponding to the operations performed in the interface and reuse it in your own scripts.

Comment utiliser Hygie ? How to use Hygie

Le fonctionnement est volontairement simple : vous lancez Hygie depuis R, vous importez vos données, vous effectuez vos transformations dans l'interface, puis vous récupérez votre résultat et, si vous le souhaitez, le code R correspondant. The workflow is intentionally simple: launch Hygie from R, import your data, perform transformations through the interface, then retrieve your result and, if desired, the corresponding R code.

Cas 1 : Nettoyer un fichier contenant des erreurs Case 1: Cleaning a dataset containing errors

Nettoyage Cleaning

Un fichier peut contenir plusieurs fois la même personne, des informations absentes ou des différences de saisie comme « homme », « Homme » ou « HOMME ». Hygie permet d'identifier ces problèmes et de les corriger avant de poursuivre l'analyse. A dataset may contain duplicate records, missing information or inconsistent entries such as "male", "Male" or "MALE". Hygie helps identify and correct these problems before analysis.

À propos de Hygie About Hygie

Hygie est un outil conçu pour rendre la préparation des données plus simple, plus visuelle et plus accessible. Hygie is a tool designed to make data preparation simpler, more visual and more accessible.

Avant de produire un graphique, une moyenne, un modèle statistique ou une analyse, il faut généralement commencer par une étape beaucoup moins visible : préparer les données. Before producing a chart, an average, a statistical model or an analysis, there is usually a less visible step: preparing the data.

Cette préparation peut consister à supprimer des doublons, traiter des informations manquantes, modifier des variables, réunir plusieurs fichiers ou réorganiser un tableau. Hygie cherche à rendre ces opérations accessibles à travers une interface graphique tout en restant connecté à l'écosystème R. This preparation may involve removing duplicates, handling missing information, modifying variables, combining datasets or reshaping tables. Hygie makes these operations accessible through a graphical interface while remaining connected to the R ecosystem.

Pourquoi Hygie ? Why Hygie?

Une grande partie du travail d'analyse se déroule avant même de produire le premier graphique ou de lancer le premier modèle. Il faut d'abord comprendre les données, repérer leurs problèmes, les nettoyer et les organiser.

Much of the work of data analysis happens before producing the first chart or running the first model. Data first needs to be understood, checked, cleaned and organized.

Hygie est né de cette idée : permettre à un utilisateur de réaliser visuellement les principales opérations de préparation des données, sans devoir connaître immédiatement toutes les commandes R nécessaires.

Hygie was born from this idea: allow users to perform common data preparation operations visually without having to know every R command from the beginning.

Ma philosophie My philosophy

Un bon outil de données ne devrait pas seulement produire un résultat. Il devrait aussi aider l'utilisateur à comprendre ce qu'il fait, à vérifier son travail et à pouvoir le reproduire.

A good data tool should not only produce a result. It should also help users understand what they are doing, verify their work and reproduce it.
