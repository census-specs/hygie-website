hygie R package

Hygie — Traitement Interactif des Données sous R Hygie — Interactive Data Processing in R

Un outil de préparation et de nettoyage de données inspiré de PowerQuery pour R, avec interface graphique interactive. A PowerQuery-inspired data preparation and cleaning tool for R, featuring an interactive GUI.

Installation Rapide Quick Installation

Installez la version de développement directement depuis GitHub via le paquet remotes : Install the development version directly from GitHub using the remotes package:

R Script

remotes::install_github("census-specs/hygie")
