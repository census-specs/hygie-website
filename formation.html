Apprendre à préparer ses données avec Hygie

Hygie n'a pas pour objectif de remplacer R. Il propose un chemin plus visuel pour comprendre les opérations de préparation des données, les appliquer étape par étape et retrouver le code R correspondant.

Débutant en RVous pouvez commencer par l'interface et apprendre progressivement le vocabulaire.
Étudiant ou enseignantUtilisez Hygie pour visualiser concrètement les étapes d'un nettoyage de données.
AnalysteUtilisez-le pour accélérer la préparation tout en gardant une trace reproductible du travail.

1. Comprendre le problème avant de nettoyer

Une donnée « incorrecte » n'est pas toujours une donnée à supprimer. Une valeur manquante peut être légitime, un outlier peut correspondre à une observation réelle et un doublon peut être intentionnel. La première compétence est donc de diagnostiquer avant de modifier.

Principe : inspecter → comprendre → décider → transformer → vérifier.

2. Importer et découvrir un jeu de données

Étape 1 — lancer Hygie

Après installation du package, Hygie se lance simplement avec :

library(hygie)
hygie()

Étape 2 — importer

Importez votre fichier depuis l'interface. Le but est d'abord de regarder la structure : nombre de lignes, variables, types et premières observations.

Étape 3 — poser quelques questions

  • Quelles variables sont numériques, textuelles, catégorielles ou temporelles ?
  • Où sont les valeurs manquantes ?
  • Existe-t-il des doublons ?
  • Les modalités sont-elles homogènes ?
  • Les valeurs extrêmes semblent-elles plausibles ?

3. Inspecter la qualité des données

Hygie permet maintenant d'inspecter les problèmes directement depuis l'aperçu. Les badges associés aux variables signalent notamment les valeurs manquantes et les valeurs aberrantes, tandis que les doublons sont inspectables dans le tableau.

Valeurs manquantesRepérer les lignes concernées avant de choisir une stratégie : conserver, supprimer ou imputer.
Valeurs aberrantesExaminer leur position avec un boxplot avant de décider si elles sont réellement erronées.
DoublonsRevenir aux lignes concernées et vérifier leur signification avant suppression.

Attention : une détection statistique est une alerte, pas automatiquement une correction.

4. Transformer sans perdre la trace du travail

Chaque opération de préparation doit être comprise comme une étape du pipeline. Renommer une variable, recoder une modalité, convertir un type ou créer une variable ne sont pas des actions isolées : elles construisent progressivement un nouveau jeu de données.

Exemple

Supposons une variable sexe contenant F et M. Après vérification des modalités, on peut la recoder en libellés plus explicites.

df[["sexe"]] <- dplyr::recode(
  as.character(df[["sexe"]]),
  "F" = "Féminin",
  "M" = "Masculin"
)

Le principe important est que l'opération effectuée visuellement doit pouvoir être retrouvée dans le code généré par Hygie.

5. Comprendre les valeurs aberrantes avec le boxplot

Pour une variable numérique, Hygie utilise la règle classique de l'écart interquartile. Le boxplot permet de visualiser la distribution centrale et les observations qui s'en éloignent.

Q1  = quantile(x, 0.25, na.rm = TRUE)
Q3  = quantile(x, 0.75, na.rm = TRUE)
IQR = Q3 - Q1

borne_basse = Q1 - 1.5 * IQR
borne_haute = Q3 + 1.5 * IQR

Une observation située au-delà de ces bornes est signalée comme potentiellement aberrante. Cela ne signifie pas qu'elle est fausse : il faut revenir à la ligne concernée et au contexte de collecte.

6. Sauvegarder un travail et le reprendre

Un nettoyage sérieux ne devrait pas disparaître à la fermeture de l'application. Hygie permet de sauvegarder un projet au format .hygie, avec les éléments nécessaires pour retrouver le travail effectué.

Bon réflexe : sauvegardez le projet dès que vous avez commencé un pipeline important, puis conservez aussi le script R généré avec vos autres documents d'analyse.

7. De Hygie vers R

La meilleure manière d'utiliser Hygie est de considérer l'interface comme un pont vers R. L'utilisateur peut commencer graphiquement, observer le code généré, le copier, le lire puis progressivement apprendre à le modifier.

Je découvreJe travaille principalement avec l'interface.
J'apprendsJe compare chaque action à son code R.
Je maîtriseJe reprends le script et poursuis mon analyse directement dans R.

Mini-parcours proposé

  1. Importer un fichier imparfait.
  2. Examiner les types et la structure.
  3. Identifier manquants, doublons et aberrantes.
  4. Corriger une ou deux variables.
  5. Vérifier le résultat après chaque étape.
  6. Copier le script généré.
  7. Sauvegarder le projet .hygie.
  8. Ouvrir le script dans RStudio et comprendre chaque commande.
Envie d'essayer ?

Installez Hygie, chargez un petit jeu de données et commencez par l'inspection. Pour apprendre, choisissez volontairement un fichier imparfait : les problèmes deviennent alors des occasions de comprendre.
